# Notes on the Surya papers, repository and Hugging Face artefacts

These are working notes made before running anything, used to decide what could be reproduced on a CPU machine. Every number in them was copied from the source named next to it.

- `surya_paper_results.md`: every quantitative result in the Surya paper (arXiv 2508.14112 v2), with the data split, metric, checkpoint and compute behind each one, and the inconsistencies noticed while copying.
- `suryabench_paper_results.md`: the SuryaBench datasets and baseline tables (arXiv 2508.14107 v1 and the *Scientific Data* version).
- `repo_runnable_paths.md`: what each script in NASA-IMPACT/Surya needs (data, checkpoints, GPU) and which paper number it can or cannot reproduce.
- `hf_inventory.md`: the models and datasets under nasa-ibm-ai4science, with file sizes, licences and commits.

Paths under `/home/user/work/...` or `/tmp/...` refer to raw downloads that are not included in this repository.
