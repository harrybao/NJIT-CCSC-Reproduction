# Citation records exactly as linked from the CCSC and CCDC pages

Retrieved 2026-10-13, after network access to `nature.njit.edu` was enabled.

**How the buttons work.** `https://nature.njit.edu/solardb/ccsc` builds its 19 tiles with `js/script.js` → `getCCSCPageData()` from
`ccsc_pages/pages_data.json` (saved here as `ccsc_pages_data.json`). The tile title links to `github.com/ccsc-tools/<repo>`, and
the **Citation** button links to the tool's **Zenodo record**. `https://nature.njit.edu/solardb/ccdc` builds its cards from
`ccdc_pages/pages_data.json` (`ccdc_pages_data.json`).

**How the citation text was obtained.** Zenodo itself returned HTTP 504 (gateway time-out) from this environment. Each record's DOI
(10.5281/zenodo.<record>) was therefore resolved through DataCite, the registry Zenodo deposits its metadata to:
* APA text and BibTeX via doi.org content negotiation (`ccsc_citations.bib`);
* full metadata in `datacite_<page>.json`;
* script: `scripts/citations/fetch_ccsc_citations.py`.

## Notes

* The Citation buttons cite the **software/data archives** on Zenodo, not the journal papers. Paper references are in `../README.md` and `../../tool_inventory.md`.
* For 13 tools the archive is a GitHub release tag (e.g. FlareML v1.5). The reproduction checked whether the cited release differs from the GitHub HEAD that was run; see `../../reports/CCSC_Reproduction_Report.md` §3.5.
* Several Zenodo links on the CCSC page differ from the DOI badges in the GitHub READMEs. For example, FlareML: page → 10.5281/zenodo.7506997 (v1.5), README → 10.5281/zenodo.5634114. The page's links are treated as authoritative.
* Spelling variants appear in the deposited metadata: "Abdullah" (MIST, LLMFlare) and "Alobail" (SYMHnet) for Abduallah and Alobaid.
